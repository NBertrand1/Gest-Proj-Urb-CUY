# Gestion des projets urbains — CUY

**Application web de gestion et de suivi de projets urbains**  
**Urban Projects Management and Tracking Web Application**

## Présentation | Overview

Ce projet a été réalisé dans le cadre d'un stage à la Communauté Urbaine de Yaoundé (CUY). Il vise à faciliter l'organisation et le suivi des projets urbains à travers une interface centralisée.

This project was developed during an internship at the Yaoundé City Council (CUY). It aims to support the organization and monitoring of urban projects through a centralized interface.

## Fonctionnalités | Features

- Gestion des projets / Project management
- Suivi des tâches / Task tracking
- Affectation des utilisateurs / User assignment
- Gestion des échéances / Deadline management
- Tableau de bord / Dashboard

## Technologies | Tech stack

- Frontend: React
- Backend: Node.js avec ExpressJS
- Authentification: JWT
- Téléversement des photos: Multer
- Base de données: MySQL
